## Data source (OGC WFS)

This project uses the MobiData Baden-Württemberg parking dataset via WFS (GeoServer):

- WFS GetFeature (GeoJSON):
  https://api.mobidata-bw.de/geoserver/ows?service=WFS&request=GetFeature&version=2.0.0&typeNames=MobiData-BW:park-api_car_on-street&outputFormat=application/json
