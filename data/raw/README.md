# Data

This repository is designed to work with **open web services** (e.g., OGC WFS) and does **not** ship large datasets.

Recommended workflow:
- `raw/`: optional local inputs (not tracked by git)
- `processed/`: derived outputs (not tracked by git)

If your thesis case study uses a specific service (e.g., parking WFS), document the endpoint and schema in `docs/`.
